# Support

StackGenome is maintained in the public Aetherexa repository.

## Report a bug

Open an issue at:

https://github.com/Aetherexa/StackGenome/issues

Please include:

- StackGenome version
- VS Code version
- operating system
- project ecosystem/package manager
- relevant manifest or lockfile type
- steps to reproduce
- expected and actual behavior

Do not attach private source code, credentials, tokens, or proprietary manifests unless you are comfortable sharing them publicly.

## Feature requests

Use GitHub Issues for new ecosystem adapters, package knowledge, health checks, and report improvements.

## Security

If you believe you found a security issue, do not publish credentials or sensitive exploit details in a public issue. Contact the repository maintainers through GitHub first so an appropriate private reporting path can be arranged.
