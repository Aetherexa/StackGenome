# StackGenome

> Project ecosystem intelligence for developers and AI assistants.

StackGenome is a language-agnostic VS Code extension that analyzes a project's dependency ecosystem, versions, frameworks, runtimes, tooling, capabilities, compatibility, and implementation options.

## Product boundary

- **StackGenome** understands the project's technology toolbox.
- **RepoLens** understands source-code structure, relationships, and change impact.
- **Copilot Toolkit** can consume both forms of intelligence to build better AI context.

Development is tracked through feature branches and pull requests.
